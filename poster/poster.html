How Many Bytes Does Encrypted Traffic Classification Actually Need?

Observation Budgets, Padding Effects, and an Adaptive Early-Exit Classifier for Raw-Byte Traffic

Muhammad Talha Arshad (i232548), Zain Shahid (i232582)

BS Data Science, FAST-NUCES Islamabad

Computer Networks, Research Project 2026
The Problem

Deep models classify encrypted traffic by reading a fixed prefix of each flow. That prefix is the observation budget, and it sets detection latency, memory per flow, and how early a system can act.

Across 12 recent studies (2025-2026) the budget is 5 to 20 packets, or 784 to 1024 bytes, and in no case is it measured. Where a reason is given it is architectural, not empirical.

Why this is not just an unexamined hyperparameter. Flows are short and heavy-tailed: the median ISCX session is 274 bytes. A 1024-byte budget therefore pads most sessions, so raising the budget raises the padding fraction. Accuracy and padding are confounded by construction, and no published result separates them.

Proposed Method
Fig. 1. Capture parsing, sessionization and anonymisation run once. Only the dashed region repeats per budget, so the budget is the sole variable along a sweep.
  • One store, many budgets. A single pass writes a 2048-byte HDF5 session store that is sliced per budget, so sessionization, deduplication and class balance cannot drift between points on the curve.
  • A leakage gate, not a caveat. Three probes run on byte positions alone; the pipeline halts unless anonymised identifier bytes are provably unlearnable.
  • Padding decomposed. A fourth input mode separates the learned byte embedding from the explicit PAD symbol, which the literature changes together.
  • Causal early exit. Dilated causal convolutions with per-position normalisation guarantee head k sees only the first k bytes, so “bytes read” is a real cost rather than a claim.

Reading more actively hurts. USTC macro-F1 falls from 0.9731 at 512 B to 0.9367 at 1500 B. McNemar finds 2488 sessions correct at 512 B but wrong at 784 B, against 94.

Not an artefact of the architecture. A byte transformer on the same store, split and seeds is not separable from a 2017 CNN and saturates at the same packet budget.

Conclusion
  • Saturation is a property of where the discriminative bytes lie, not of the network reading them.
  • Published budgets are 5 to 7 times larger than the measurements support.
  • Split policy outweighs every architectural effect here, so it must be stated for any cross-paper comparison.
Reproducibility. USTC-TFC2016 and ISCX VPN-nonVPN, group-wise splits where the corpus allows, 3 seeds (8 for the split study), seed variance and McNemar’s exact test on every headline claim.
